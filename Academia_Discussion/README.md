# Academia Discussion

This folder separates algorithm-level interpretation from the compact project README. Each file discusses the role, observed behavior, and limitation of one solver under the same PANCAKE benchmark. The two redesigned research methods, **DWOA-AVNS** and **DFOX-APNS**, additionally document literature basis, design hypotheses, pseudocode, and a textual flowchart.

Algorithms: GA, Tabu Search, GA+Tabu, ACO, DPSO, DWOA-original, DWOA+Tabu-fixed, DWOA-AVNS, DFOX-Base, and DFOX-APNS.
