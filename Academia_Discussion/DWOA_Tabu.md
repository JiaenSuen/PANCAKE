# DWOA + Tabu (corrected hybrid)

DWOA+Tabu-fixed evaluates the intended hybrid after correcting an implementation issue in the legacy C# project where the Tabu-refined solution was not retained by the whale stage. The corrected pipeline first performs DWOA exploration and then spends the remaining evaluation budget on Tabu intensification from the current best solution. It achieved **14.47% median RPD**, **0% Success@5%**, **1.02× GA-relative convergence efficiency**, and a **4.60 mean rank**, with an **8.88% exact gap**. The hybrid is substantially stronger than DWOA-original, confirming that local refinement helps the discrete whale representation. However, its fixed two-stage schedule is less responsive than the adaptive designs. If the swarm becomes stagnant early, local search begins too late; if a landscape requires longer exploration, a predetermined switch may over-intensify. This result motivated integrating local neighborhoods inside the search process rather than treating them only as a final post-processing stage.
