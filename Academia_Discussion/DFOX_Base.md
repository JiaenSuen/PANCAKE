# DFOX-Base — Direct Discrete FOX Mapping

DFOX-Base is a deliberately conservative translation of the original 2022 FOX optimizer into PANCAKE's coupled discrete representation. It preserves FOX's **fixed 50/50 exploration–exploitation selection**: exploration uses long route/source perturbations to mimic the fox's random walk and jump, while exploitation partially aligns a candidate toward the current best prey solution. This direct mapping achieved only **39.83% median RPD**, **0% Success@5%**, **0.86× GA-relative convergence efficiency**, and a **9.67 mean rank**; its exact gap was **8.09%**. The result is analytically useful because it shows that the FOX metaphor alone does not automatically transfer to permutations. A continuous jump magnitude does not specify which order edges or source assignments should change. DFOX-Base therefore functions as an ablation baseline: the large performance gap to DFOX-APNS isolates the value of adaptive phase control, problem-specific neighborhoods, and explicit handling of coupled order/source structure.
