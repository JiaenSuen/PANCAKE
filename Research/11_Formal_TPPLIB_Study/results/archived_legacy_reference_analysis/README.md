# Archived legacy-reference derived analysis

These files were generated before the Class-3 reference-semantics audit. They treated the imported `Baseline_EEuclideo.csv` column named `OPT` as universally exact. That assumption is false for the full 100-instance subset: several rows are time-limited incumbents/open cases and later literature reports better BKS values.

The raw canonical run scores remain valid. These **derived** tables are retained only for provenance and must not be cited in the paper. Use the `*_reference_safe.*`, `literature_BKS_validation.csv`, and `reference_registry.csv` files in the parent results directory instead.
